Auto-Installer (script)

Volledig automatisch installeren

Eén commando doet alles: pakketten installeren, database aanmaken, JWT-secrets genereren en Locra EDU live zetten via PM2 met autostart.

  • Controleert Node.js versie automatisch
  • Genereert veilige, unieke JWT-secrets
  • Migreert de schooldatabase direct
  • Start via PM2 — ook na herstart van de server

🐧 Linux / macOS

curl -fsSL https://edu-locra.pieteroosterling.online/install-edu.sh | bash

🪟 Windows (PowerShell als Admin)

powershell -ExecutionPolicy Bypass -Command "irm https://edu-locra.pieteroosterling.online/install-edu.ps1 | iex"

Vereisten: Node.js ≥ 18, npm. Op Windows: voer uit in cmd.exe of PowerShell als Administrator.

Handleiding: Handmatige installatie (.zip)

01

Vereisten controleren

Zorg voor Node.js v18+, npm en unzip. Controleer:
node --version && npm --version
Installeer PM2 globaal:
npm install -g pm2

02

Uitpakken

Pak het zip-bestand uit:
unzip locra-release.zip -d locra-edu
Navigeer naar de map:
cd locra-edu

03

Backend instellen

Ga naar de servermap:
cd server && npm install
Maak .env aan met PORT=4000, JWT_SECRET en DATABASE_URL.
npx prisma db push

04

Services starten

Start de server via PM2:
pm2 start server/dist/index.js --name locra-edu-api
Sla op voor autostart:
pm2 save && pm2 startup

05

Setup Wizard

Open http://localhost:4000. Voer je EDU-licentiesleutel in, stel de schoolnaam in en maak de eerste beheerdersaccount aan.

06

Docenten toevoegen

Ga na activatie naar het beheerportaal → Gebruikers. Voeg docenten en leerlingen toe of koppel SOMtoday voor automatisch importeren.

Problemen oplossen & Beheer

Server herstarten (Windows)

Als je je terminal per ongeluk hebt gesloten of de server wilt herstarten, open dan een nieuwe Command Prompt (of PowerShell), navigeer naar de geïnstalleerde map en typ:

cd C:\Pad\Naar\Je\Installatie\locra-edu-release
pm2 delete all
pm2 start server/dist/index.js --name "locra-edu-api" --interpreter node

Server herstarten (Linux / macOS)

Na een herstart van de machine:

pm2 resurrect
# Of handmatig:
cd /opt/locra-edu
pm2 start server/dist/index.js --name locra-edu-api
