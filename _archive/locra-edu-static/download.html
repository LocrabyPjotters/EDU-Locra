Auto-Installer (script)

Volledig automatisch installeren

Eén commando doet alles: pakketten installeren, database aanmaken, JWT-secrets genereren en Locra EDU live zetten via PM2 met autostart.

curl -fsSL https://edu-locra.pieteroosterling.online/install-edu.sh | bash

Vereisten: Linux/macOS, Node.js ≥ 18, npm, unzip

Handleiding: Handmatige installatie (.zip)

01

Vereisten controleren

Zorg voor Node.js v18+, npm en unzip. Controleer:
node --version && npm --version
Installeer PM2 globaal:
npm install -g pm2

02

Uitpakken

Pak het zip-bestand uit:
unzip locra-release.zip -d locra-edu
Navigeer naar de map:
cd locra-edu

03

Backend instellen

Ga naar de servermap:
cd server && npm install
Maak .env aan met PORT=4000, JWT_SECRET en DATABASE_URL.
npx prisma db push

04

Services starten

Start de server via PM2:
pm2 start server/dist/index.js --name locra-edu-api
Sla op voor autostart:
pm2 save && pm2 startup

05

Setup Wizard

Open http://localhost:4000. Voer je EDU-licentiesleutel in, stel de schoolnaam in en maak de eerste beheerdersaccount aan.

06

Docenten toevoegen

Ga na activatie naar het beheerportaal → Gebruikers. Voeg docenten en leerlingen toe of koppel SOMtoday voor automatisch importeren.
