Authenticatie

Alle verzoeken aan de Locra PrivAI™ API vereisen een geldige API-sleutel. Verstuur deze als een Bearer token in de HTTP Authorization header:

Authorization: Bearer privai_live_8f3d91c7b5204ef8a961023d8c11e40a

Voor de Anthropic Claude berichten-endpoint wordt ook de X-API-Key: privai_live_... header ondersteund.

POST /v1/chat/completions

Volledig OpenAI-compatibel endpoint. Ondersteunt zowel synchrone JSON-antwoorden als realtime Server-Sent Events (SSE) streaming.

Parameters in Request Body

Veld Type Beschrijving
model * string ID van het soevereine model (bijv. locra-privai-pro, locra-privai-fast of alias zoals gpt-4o).
messages * array Lijst van berichtobjecten met role ("system", "user", "assistant") en content.
stream boolean Standaard false. Zet op true voor realtime token-by-token streaming via SSE.
temperature number Sampling temperatuur tussen 0.0 en 1.0 (standaard 0.7).
max_tokens integer Maximaal aantal te genereren tokens (standaard 2048).

POST /v1/messages

Anthropic Claude-compatibel endpoint. Accepteert een aparte system parameter en Claude SSE-events (message_start, content_block_delta, message_stop).

GET /v1/attestation

Haalt een cryptografisch hardware-attestatierapport op, ondertekend door de AMD Secure Processor (ASP) van de server in Amsterdam. Bevat de actuele X25519 publieke sleutel voor client-side envelope encryptie.

GET /v1/models

Geeft de actieve soevereine modellen terug met hun context-lengte en specificaties.

GET /v1/usage

Geeft real-time inzicht in tokenverbruik, resterende maandquota en gemiddelde latency. Bevat gegarandeerd 0 bytes aan prompt- of chatinhoud.
