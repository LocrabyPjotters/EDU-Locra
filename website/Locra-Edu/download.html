Stap-voor-stap

In 15 minuten operationeel op school

Volg deze stappen om Locra Core lokaal of in de schoolcloud in te richten.

1

Vereisten Controleren

Controleer of Node.js v18+ en PM2 geïnstalleerd zijn op de host server:
node -v && npm -v

2

Pakket Uitpakken of Klonen

Download het releasepakket of kloon de repository:
git clone https://github.com/LocrabyPjotters/EDU-Locra.git

3

Dependencies & Database

Installeer pakketten en initialiseer de SQLite/Postgres database:
npm run install:all && cd server && npx prisma db push

4

Productie Build Draaien

Compileer de backend en de snelle Vite frontend:
npm run build

5

Autostart via PM2

Laat de service 24/7 draaien met automatische herstart bij reboot:
pm2 start server/dist/index.js --name locra-edu && pm2 save

6

Setup Wizard & Activatie

Open http://localhost:4000 in je browser. Vul je licentiesleutel in en koppel direct je docenten via SOMtoday of Entree Federatie.
