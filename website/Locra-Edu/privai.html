Beveiligingsarchitectuur

OpenPCC: Waarom Locra PrivAI™ écht zero-access is

Bij traditionele cloud-AI moet je het techbedrijf op hun blauwe ogen geloven dat ze niets opslaan. Bij Locra PrivAI™ dwingt het silicium van de processor af dat afluisteren wiskundig onmogelijk is.

Confidential Computing Dataflow

Client → Blind Gateway (Control Plane) → AMD SEV-SNP TEE Enclave (Data Plane)
Hardware Root of Trust Verified
1

Remote Attestation

De client vraagt via /v1/attestation de cryptografische chip-handtekening op en verifieert dat de ongewijzigde open-source Locra TEE software draait.

2

Envelope Encryptie

De prompt wordt lokaal versleuteld met X25519 + AES-256-GCM. De Blind Gateway in Amsterdam ziet alleen onleesbare ciphertext.

3

TEE Enclave Inferentie

Alleen binnen het hardwarematig versleutelde RAM van de processor wordt de tekst ontsleuteld. Het model genereert streaming tokens op volle GPU-snelheid.

4

Ephemeral RAM Scrub

Na het voltooien van de stream worden alle geheugenbanken direct overschreven met nullen (zero retention). Alleen tokenaantallen gaan naar de gateway.

✓

Wat de Control Plane WÉL registreert

Uitsluitend niet-gevoelige operationele metadata voor monitoring, SLA-kwaliteit en maandelijkse facturatie:

  • Aantal tokens: Input tokens en output tokens (voor quota).
  • Responstijd (latency): Tijd in milliseconden tot de eerste token.
  • Gekozen model: Bijv. locra-privai-pro of locra-privai-fast.
  • API-Key prefix: Geanonimiseerde identificatie (bijv. privai_live_8f3d...).
  • Tijdstempel: Datum en tijd van de request.
  • Datacenter node: Welk serverrack in Amsterdam de query verwerkte.
✕

Wat technisch NÓÓIT ingezien of gelogd kan worden

Dankzij hardwarematige RAM-encryptie (AMD SEV-SNP) is dit fysiek onmogelijk voor Locra, hostingpartners en derden:

  • 0 Bytes promptinhoud: Vragen, PTA-opdrachten, verslagen of documenten.
  • 0 Bytes chatberichten: De conversatiegeschiedenis en antwoorden.
  • 0 Bytes bestandsbijlagen: Geüploade PDF's of bronbestanden.
  • Geen modeltraining: Jouw data wordt nooit gebruikt om modellen te trainen.
  • Geen schijfopslag (disk logging): Alles draait uitsluitend in vluchtig RAM.
  • Geen IP-adres tracking: Netwerkverkeer wordt niet gekoppeld aan leerlingprofielen.

Vervang OpenAI of Claude in 1 regel code

Geen complexe herprogrammering nodig. Wij ondersteunen de officiële OpenAI en Anthropic SDK-protocollen. 

from openai import OpenAI

# Wijs base_url simpelweg naar de soevereine Locra PrivAI™ gateway in Amsterdam
client = OpenAI(
    base_url="https://api.privai.locra.nl/v1",
    api_key="privai_live_8f3d91c7b5204ef8a961023d8c11e40a"
)

response = client.chat.completions.create(
    model="locra-privai-pro",
    messages=[
        {"role": "system", "content": "Je bent een didactische tutor volgens het RTTI-model."},
        {"role": "user", "content": "Leg de stikstofcyclus uit aan een 4 VWO leerling."}
    ],
    stream=True
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="", flush=True)

Veelgestelde vragen over Locra PrivAI™

Kan Locra als beheerder écht niet meekijken in prompts?

Nee, dat is technisch onmogelijk. De servers draaien in AMD SEV-SNP hardware enclaves. Het werkgeheugen (RAM) van de server wordt realtime door de processor geëncrypt met een sleutel die in het silicium van de CPU zit. Zelfs een engineer met fysieke toegang tot het moederbord of een root-beheerder ziet in een RAM-dump uitsluitend willekeurige ruis.

Waarom is dit veiliger dan de 'zero-data-retention' van OpenAI?

Bij commerciële Amerikaanse partijen moet je vertrouwen op een juridische belofte en contractuele voorwaarden. De data staat tijdens de berekening onversleuteld in het geheugen van Amerikaanse servers die vallen onder de US CLOUD Act. Bij Locra PrivAI™ dwingt de fysieke hardware de geheimhouding af onder 100% Nederlandse rechtsmacht.

Kunnen we dit koppelen aan onze bestaande Locra Core schoolserver?

Jazeker! In Locra Core kies je bij AI-Modellen simpelweg de optie "Locra PrivAI™ (Sovereign NL)" en voer je jouw licentiesleutel in. Je schoolserver schakelt dan automatisch over naar de veilige Nederlandse TEE-cluster zonder lokale GPU-vereisten.

Sluiten we een Verwerkersovereenkomst (DPA) af?

Jazeker. Wij leveren een standaard DPA conform het officiële Privacyconvenant Onderwijs v4.0. Omdat Locra PrivAI™ 0 bytes chatinhoud opslaat en data end-to-end afschermt, voldoet jouw school direct aan de strengste richtlijnen van SIVON en de Autoriteit Persoonsgegevens.
